# Assets

All decorative elements are SVG so the finished poster is fully vector.

| File | What | Source |
|---|---|---|
| `kinit-logo.svg` | KInIT wordmark with tagline | wordmark: official vector from kinit.sk; tagline traced from the template |
| `kinit-k.svg` | KInIT "k" mark (contact box) | official vector from kinit.sk |
| `but-logo.svg` | Brno University of Technology logo (EN) | official vector from the vut.cz icon sprite |
| `mascot.svg` | pixel-art speech-bubble "k" mascot | rebuilt as an exact 13x21 pixel grid from the template PNG |
| `wave.svg` | red wavy footer line | traced from the template PNG with potrace |

The KInIT and BUT logos belong to their respective institutions and are
included only for producing posters affiliated with them.
